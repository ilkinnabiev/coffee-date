# Маленькое приглашение

Одностраничное приглашение на свидание с котиком.

- «Да» сразу открывает [@IlkinNabiev](https://t.me/IlkinNabiev).
- «Нет» меняет положение при касании, наведении мыши или нажатии клавиши.
- Кнопки не пересекаются; на коротком экране игровая область прокручивается в видимую часть.
- Картинка и шрифты загружаются с самого сайта. Сборка и серверная часть не нужны.

## Запуск

```sh
python3 -m http.server 4173
```

Открыть `http://localhost:4173`.

## GitHub Pages

Публикация из корня ветки `main`. Файл `.nojekyll` отключает обработку Jekyll.

Контакт меняется в `index.html`, оформление — в `styles.css`, поведение кнопки — в `script.js`.

## Проверка

Проверено в WebKit с сенсорным вводом: 390×664, 375×548, 320×460, 430×780 и 844×320. Для каждого размера проверены 16 попыток нажать «Нет», границы экрана, отсутствие пересечений с «Да», поворот экрана, клавиатура и переход в Telegram. Отдельно проверены мышь и режим уменьшенной анимации.

На физическом iPhone проверка не выполнялась.

## Шрифты

Nunito и Shantell Sans распространяются по SIL Open Font License. Тексты лицензий находятся в `assets/`.
